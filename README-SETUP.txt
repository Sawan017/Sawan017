1. OVERVIEW & ARCHITECTURAL DESIGN AUTHORITY
--------------------------------------------------------------------------------
Rebuilt from scratch following the exact layout, visual richness, and compositional
proportions demonstrated in the reference video playbook (Sushmitadasari/Sushmitadasari),
custom-tailored to the authentic developer identity of Sawan Sahani (@Sawan017).

Core Design Tenets:
- Dark, rich Midnight Emerald foundation (#10251F, not black, not charcoal).
- Pure vector XML graphics with explicit numerical viewBox and width/height dimensions.
- Zero XML entity bugs (&bull;, &mdash; stripped in favor of native UTF-8 or standard entities).
- Zero sub-resource dependencies (<image href="..."> removed for standalone SVG rendering).
- Fully responsive on all device widths and GitHub desktop/mobile applications.
- Accompanied by 100% matching high-resolution PNG fallbacks rendered via headless Edge.

--------------------------------------------------------------------------------
The `.github/workflows/snake.yml` workflow generates the contribution snake eating
GitHub activity squares daily at 00:00 UTC and on every push, colored in Midnight
Emerald tokens (#10251F, #142E25, #19392D, #32805B, #68A786).
